## B. Browser-only, no server, no key, no data sent

Fully local: **KaTeX, Mermaid, Tesseract.js (WASM), pdf.js, pdf-lib, DiceBear npm library (MIT code, CC0 styles), self-hosted Google Fonts files.** Remote but key-less, sending only the query: Wikipedia/Wiktionary (needs `Api-User-Agent`), Free Dictionary, Datamuse (until 2027), Crossref, OpenAlex, Open Library, arXiv, Frankfurter, Openverse anonymous, Kroki/mermaid.ink/QuickChart URLs, Nominatim (1 rps, attribution). Unsplash, Pexels, Pixabay, DeepL, OCR.space, iframely need a secret and therefore a proxy.

## C. Must not receive user document text

- **Semantic Scholar** licence: "AI2 will use the data and information that Licensee provides and transmits to call or use the API ("Licensee Data") for the purpose of providing and improving the API". Send DOIs/titles only.
- **LanguageTool public API**: "Do not send automated requests"; 20KB cap; no privacy statement on the page. Whole-document checks against the public endpoint are outside its stated use; self-host for that.
- **DeepL Developer plan**: sends text by design; a "No data training" row exists on the plan table but which plans tick it did not survive text extraction, so unverified.
- **Datamuse**: customer-facing use requires describing the app to them first.
- **Kroki, mermaid.ink, QuickChart, Microlink/iframely**: diagram source, chart data and URLs travel in the request with no privacy terms opened; treat as public.
- **Nominatim**: client-side autocomplete forbidden; platform-generated use forbidden.
