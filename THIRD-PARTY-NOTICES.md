# Third-party notices

frontmatter ships with the following third-party fonts, icons and libraries. Each notice below is the one its licence asks for. This file is linked from the published-page footer and the desktop About panel once those ship. Added 17 September 2026 (audit finding F073).

## Fonts

**Google Sans Code**, Copyright 2025 The Google Sans Code Project Authors (github.com/googlefonts/googlesans-code). Licensed under the SIL Open Font License, Version 1.1. Used in the plan screens under docs/mvp0/screens (embedded in fonts.css) and, if adopted, in the app as the code face. The licence text follows.

**Google Sans Flex**, Copyright 2015 The Google Sans Flex Authors (https://github.com/googlefonts/googlesans-flex). Licensed under the SIL Open Font License, Version 1.1. Named here because the "Google Sans" family the app loads through Google Fonts (src/app/layout.tsx, next/font/google) has been served by Google Fonts since 9 December 2025 and no separate licence file for it was found in the google/fonts repository on 17 September 2026; until that is settled, the Flex licence is the one on record and the question is marked unverified in the plan.

**Mosvita** (Yukita Creative) was embedded in the plan PDFs built before 17 September 2026. No licence text could be produced for it, so it is no longer embedded; the PDFs now use the Google Sans faces above.

## Icons

**Material Symbols** (Google), the Rounded set at weight 400, as SVG path data in src/shared/presentation/material-symbol-paths.ts and inline in the plan screens. Licensed under the Apache License, Version 2.0: https://github.com/google/material-design-icons/blob/master/LICENSE
