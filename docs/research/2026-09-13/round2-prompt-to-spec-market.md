## Already in the corpus (cite, don't re-derive)

- **GitHub Spec Kit** — `spec.md → plan.md → tasks.md` + `constitution.md`, 37 agent integrations. Re-verified today via `api.github.com/repos/github/spec-kit`: **136,066 stars, 12,226 forks**, MIT, last push 2026-09-12 (up from the corpus's earlier count — still climbing). v1.0.0 shipped 2026-08-21. HN reception mixed: some call the tutorials "pretty elementary," question consistency and novelty vs formal methods; corpus itself flags "default-tool gravity" — many run it because it's GitHub's, not because they benchmarked it. Free/MIT, no paid tier; distributed as an installer CLI, not a hosted product. [github.com/github/spec-kit](https://github.com/github/spec-kit), [Hacker News #45577377](https://news.ycombinator.com/item?id=45577377)
- **AWS Kiro** — `requirements.md` (EARS)/`design.md`/`tasks.md`, IDE-only, the only one with real verification (property-based tests generated from requirements, run against the implementation). Proprietary, no OSS license. Corpus: 4,231 stars on its issue-tracker repo (not the product itself).
- **Tessl** — corpus finding stands: **pivoted away from spec-generation entirely**, is now a skills/plugin registry with governance and evals. Its CLI has no spec/build command. `tesslio/cli` sits at 71 stars vs OpenSpec's 66,571 (937.6x gap) — a cautionary data point on this category's staying power.
- **BMAD-METHOD** — persona-driven agents produce briefs/PRD/architecture/stories, installed via `npx bmad-method install`. 52,419 stars / 5,964 forks, MIT (per npm), last commit 2026-08-28 per corpus.
- **Cursor** — ships rules (`.cursor/rules/*.mdc`), not specs; no persisted plan artifact. Corpus notes docs.cursor.com is a client-rendered SPA that resists curl, so mechanics there are lower-confidence.
- **Claude Code / Factory** — plan mode is a session state, not a file; corpus's phrase: "the IDE has conceded the artifact."

Delivery: a project dashboard the user reads/exports from, output feeds "Cursor, Windsurf, and other AI coding tools" via context files, not an MCP link. **ChatPRD** (chatprd.ai) — PM-facing chat that generates PRDs/user stories, not aimed at coding agents directly; output is a doc a PM then hands to engineering (Slack/Notion/Linear/Google Drive export, MCP integration listed in nav). Pricing verified from `/pricing`: **Free** $0/mo (3 chats, limited), **Pro $15/mo** billed $179/yr (unlimited docs, GPT-4o/Claude/o1, templates, integrations), **Teams $29/seat/mo** billed $349/seat/yr (shared workspace, real-time collaboration), **Enterprise** custom (SSO). **Task Master** (`eyaltoledano/claude-task-master`) — an MIT("Other"/NOASSERTION)-licensed CLI that turns a PRD into a tracked task graph inside the repo itself (`.taskmaster/` or `.cursor/rules/dev_workflow.mdc`), designed to drop into Cursor, Lovable, Windsurf, Roo Code, Claude Code. ## Promotion / growth mechanics

Spec Kit's growth reads as **platform-gravity, not marketing**: it is a GitHub product, defaults win when they ship inside the tool developers already use, and HN threads (2 launches, #45154355 and #45798473, plus the later #45577377 retrospective) show it climbing "month over month" to 132k+ stars by August 2026 largely on that basis, with critics explicitly naming the effect. No comparable launch-post evidence was found this pass for CodeGuide, ChatPRD, or Traycer (all closed-source SaaS with no GitHub-star proxy for adoption) — their traction is unverifiable from public sources short of the vendor's own claims (e.g. ChatPRD's "100,000+ PMs," unverified).

## Retention evidence

No new evidence beyond what the corpus already found: `b1-spec-driven-development-market.md` line 161 stands — Tessl abandoned the spec-generation pitch, Roo Code archived at 1.96M installs, `get-shit-done` became a redirect after 64,629 stars, and the only independent census (SPECMINE) found specs and code co-changing in just 581 of 73,030 repos — consistent with "generate once, abandon." Task Master's 4.5-month-stale last push (found this pass) is a small additional data point in the same direction: a widely-starred (28k) tool that has gone quiet.

## Gaps a markdown-native editor could fill — and the honest crowding check

- **Every generator above stops at file/doc creation.** None keeps the generated kit *live* at a shareable, editable link the way the founder's funnel proposes — CodeGuide's output lives in its own dashboard, ChatPRD's in its chat history/exports, Task Master's in repo files, Traycer's in its desktop app. A markdown editor that generates the kit **and** hosts it at an unguessable GUID **and** stays the place you keep editing it is a real gap versus all four.
- **But the corpus's own verdict from 2026-08-29 already named the crowding risk precisely**, and it applies unchanged to this new set: the category's actual incumbent is a *free, MIT-licensed CLI* (spec-kit at 136k stars, OpenSpec's npm downloads dwarfing everyone), so willingness-to-pay for "generate the spec kit" is unproven at any price point — CodeGuide charges $24–29/mo and Traycer $10–100/user/mo into that same zero-price gravity well.
- **This is a crowded space for the "generate a spec" step specifically.** Spec Kit, Kiro, BMAD, CodeGuide, Task Master, and now the founder's own funnel all do variants of prompt-to-plan-to-tasks. The differentiated part of the frontmatter pitch is not spec generation — it's the **persisted, editable, linkable, byte-exact document store** underneath it, which is closer to frontmatter's actual splice/review-state moat than to anything these six products compete on. The corpus's resolution stands: enter as rendering + hosting + editing for artifacts other tools already write, not as a seventh generator.
