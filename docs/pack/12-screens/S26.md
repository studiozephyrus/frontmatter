## Purpose

Get a thought out of your head and into the inbox note in one keystroke, without opening the
workspace and without spending a credit.

## The thing that makes it work

**One box, one destination, one key, and no cost.** Every part of that matters.

- **One box.** No title field, no folder picker, no template chooser. The destination is named on the
  box and is one tap away if it is wrong.
- **One destination.** An inbox note. Filing is a later decision, and asking for it here is what makes
  capture tools stop being used.
- **One key.** A global shortcut on the desktop, the share sheet on Android. Reaching this through the
  workspace defeats the point.
- **No cost.** No model is called, so no credit is charged, and the foot line says so.

## Entry and exit

Direction | How | Route or control
In | The global shortcut, on the desktop | `Command Shift Space`, per `docs/pack/15-INTERACTION-AND-KEYBOARD.md:62`
In | The share sheet from any application, on Android, once the app is installed | The share target
In | The AI position on the phone's bottom bar, long-pressed | `C086`
Out | Save, which writes into the inbox note and closes | The inbox note, unopened
Out | Escape, which closes and keeps nothing | No navigation
Out | Into a named document instead, from the phone's second chip | That document
Out | The install card, on the phone | The browser's own install prompt

**Nothing on this screen navigates anywhere on success.** Save closes the box and leaves the person
where they were, which on the desktop is whatever application they were using.

## Data contract

What | Direction | Port or store | Shape | When
Shortcut registration | write | The desktop shell's global-shortcut interface | The chord, once, at launch | On launch
Shared text | read | The share target, on Android | `{ title, text, url }` | On a share
Destination | read | `CaptureSettings.inbox(accountId)` | A path, defaulting to an inbox note in the notes project | On open
Append | write | `ProjectFiles.splice(path, endOfFile, bytes)` | One splice at the end of the note, with a timestamped heading | On save
Offline queue | write | `draftStore`, the same store S24 uses | The pending capture, keyed by its own id | When there is no connection
Entitlement | read | none | **No cap applies and no credit is charged** | never

**None of this is built.** At `0af3c90` there is no global-shortcut plugin in `src-tauri/Cargo.toml`,
no share target in a manifest, and no capture module in `src/`. The screen is **specified, not built**.

**A capture is an append, and an append is still a splice.** It locates the end of the note and writes
there. It does not rewrite the note, and it does not reformat what is already in it.

**The share target works only in an installed Chromium application**, at
`docs/mvp0/PRODUCT-PLAN.md` section 5, at line 612. That is why the phone shows the install card, and
it is why iOS is named as absent rather than left to fail.

## Actions

Action | Trigger | What happens | Failure behaviour | Event id
Open the box | The global shortcut | The panel opens over whatever is on screen, with the field focused | Shortcut already claimed by another application, so `E420` at launch, with the chord named | `capture.opened`
Type | Any keystroke | Text accumulates. Nothing is sent anywhere | none | `capture.typed`
Offer a chip | Text containing a tag or a date | A chip is offered. **It is never applied until it is tapped** | none | `capture.chip.offered`
Change the destination | The destination pill | A short list of recent notes, and the inbox at the top | none | `capture.destination.changed`
Save | Enter, or the save control | The text is appended under a timestamped heading, and the box closes | No connection, so the capture is queued locally and the box still closes | `capture.saved`
Close | Escape | The box closes and keeps nothing | none | `capture.dismissed`
Share from another application | The Android share sheet | The sheet opens with the text, the source and the time already in it | App not installed, so the share target is absent and nothing is offered | `capture.shared`
Install | The install card's control | The browser's own install prompt runs | Prompt unavailable, so `E421` names the browser's own menu route | `capture.install.offered`
Meet iOS | Opening the phone surface on iOS | The share route is named as absent, in plain words, with no control that would fail | none | `capture.ios.unsupported`

**A chip is an offer, never an application.** Text that looks like a tag or a date is proposed. The
bytes written are the bytes typed unless the person taps.

## States

State | When | What is shown | What the person can do
first-run | The first capture on this account | The box, plus one line naming the destination note | Type, save.
empty | The box with nothing typed | The field, the destination and the foot line. Save is inert | Type, or close.
loading | n/a. The box opens instantly and calls nothing | n/a | n/a.
partial | A queued capture waiting for a connection | Nothing here. The count appears in the workspace, on S24 | Carry on.
offline | No connection | The box works unchanged. The capture queues locally and syncs later | Type, save, close.
unauthorised | Signed out on the desktop | The box opens and writes into the local inbox file. It syncs after sign-in | Capture anyway.
over-cap | n/a. **A capture costs no credit and counts against no cap** | n/a | n/a.
AI-unavailable | n/a. No model is called | n/a | n/a.
conflict | The inbox note changed under a queued capture | The append is re-placed at the new end of the file. An append cannot conflict | Nothing.
error | The append failed | `E422`, and the text stays in the box rather than being lost | Retry, or copy it out.
degraded | The destination note has grown very large | A quiet line offering to start a new inbox note by month | Accept, or carry on.

**The box never closes on a failure.** Losing a captured thought is the one failure this screen cannot
have, so `E422` keeps the text on screen.

## Keyboard and focus

key | does
Command Shift Space | Opens the box, from anywhere on the desktop
Enter | Saves and closes
Shift Enter | A new line inside the capture
Escape | Closes and keeps nothing
Tab | Moves to the destination pill, then the chips, then back to the field

**Focus on open is the input field, with an empty value.** Nothing else on this screen is worth a
keystroke of travel.

**Focus returns to the application the person came from** when the box closes. A capture panel that
leaves focus in the browser has taken the person out of what they were doing, which is the cost this
screen exists to avoid.

**The chord is desktop only, and `docs/pack/15-INTERACTION-AND-KEYBOARD.md:62` says why**: a web page cannot
claim a system-wide chord. The web build offers no equivalent, and this file does not invent one.

## Responsive

- **The panel becomes a bottom sheet** at phone width, opened by the share sheet rather than a chord.
- **The source context appears only on the phone**, because only the share route has a source.
- **The install card appears once**, and only where an install can actually happen.
- **On iOS the share route is absent**, and the surface says so in words instead of drawing a control
  that would fail.

## Desktop differences

- **The global shortcut exists only here.** It is the whole feature on the desktop.
- **The box is a panel over the operating system**, not a page in a browser tab, so it opens over
  whatever application was in front.
- **A capture with no connection writes straight into the local inbox file**, because the desktop
  build has the file system and needs no queue.
- **The install card is absent.** The person is already installed.

## What this screen must never do

- **Never lose a captured thought.** A failure keeps the text on screen.
- **Never ask for a title, a folder or a template.** One box, one destination.
- **Never call a model**, and never charge a credit.
- **Never apply a chip the person did not tap.**
- **Never rewrite the destination note.** Append at the end.
- **Never leave focus in our window** after the box closes on the desktop.
- **Never show an install or a share control where it cannot work.**
- **Never block on the network.** A capture with no connection still saves.
