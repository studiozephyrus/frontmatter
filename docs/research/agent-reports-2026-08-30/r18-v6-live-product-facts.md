### What must change in the record

1. **§ where claim 12 sits (problem #2 / T0 justification) — delete "561 of 3,220 HN comments."** It is not reproducible and, on the strictest reading of its own words, it overstates by roughly 70×. Replace with the measured line: *"Across 17,413 unique HN comments harvested via the Algolia API on 2026-08-31, 13,731 mention sync or a sync service; **445 (3.2%) pair sync with data-destruction language and 33 assert both destruction and silence** [measured]."* Record the query list and the date in a footnote — the API's `exhaustiveNbHits: false` means any count is a snapshot, not a constant.
2. **Same section — do not rest T0's priority on comment volume.** 33 comments is a real signal about severity and a weak one about frequency. The argument that survives is *consequence*, not *count*: silent destruction is unrecoverable and undetectable, which is precisely the failure a byte-preserving splice engine with REFUSE semantics is designed to make impossible. Rewrite the justification to lead with that.
3. **§15 — rewrite the Canvas line.** "OpenAI removed Canvas in May 2026" → *"On 28 May 2026 OpenAI withdrew canvas from GPT-5.5 Instant and Thinking and replaced it with in-chat writing blocks and code blocks; paid users kept canvas only via legacy models, of which GPT-4.5 retired 26 Jun 2026 and o3 retired 26 Aug 2026 [fetched]."* The strategic read changes with the correction: OpenAI did not abandon the document surface, it **collapsed it into the chat stream** — a competitor moving toward ephemeral, not away from documents.
4. **§16 — split the Notion sentence into two and fix both.** Strike "20 responses for life" (Notion publishes no number; cite the wall, not the count). Change "raised Business ~20%" to **"+33% ($15 → $20 per seat/month billed annually, SKU-dated 2025-05)"**, and add the counter-fact in the same breath: bundling AI made Business **cheaper by 13%** for anyone who had been buying the $8 AI add-on. A record that quotes only the +33% will lose an argument with anyone who checks.
5. **§16 — qualify "+43%" as Microsoft 365 Personal.** Add Family at +30% and the underlying primary fact ($3/month, announced 16 Jan 2025) so the figure is auditable without a second lookup.
6. **§16 — restate the CMA line and add the second case.** The 27 Jul 2026 probe is about **disclosure before renewal**, not about the size of the increase; state that, and add the **14 May 2026 SMS investigation into Microsoft's business software ecosystem**. Both are open. Keep the CMA's own caveat that no finding has been made — the record should not imply Microsoft has been found to have infringed.
7. **§17 — update 172,544 → 191,997 and add the retrieval date**, because this number moves weekly. Add the rank (117th of 7,092) and Relay's price ladder ($5 / $6 / $18 per user per month); "a commercial service's bridge plugin" is stronger with the actual price points attached, and it establishes the willingness-to-pay band that Rs 299 / Rs 599 sits inside.
8. **§21 — tag both community numbers, which are currently bare.** Discord becomes **195,633 [fetched, 2026-08-31]**. The subreddit figure must carry an explicit **[SS]** and a parenthetical that Reddit now returns HTTP 403 to unauthenticated clients. If that number is going to be load-bearing anywhere (TAM, launch-channel sizing), the fix is a Reddit developer token, not another search.
9. **Standing rule this pass exposes:** four of the nine sub-claims were directionally right and numerically wrong, and every one of those four was wrong in the direction that flattered the argument. Any figure in this record that supports a thesis should be re-derived at write time from the named artifact, never carried forward from an earlier draft.
