## Purpose

See exactly what each connected service is allowed to do, and remove it from here or from the other
end.

## Entry and exit

Direction | How | Route or control
In | Settings, then the Connections section | `/settings/connections`
In | A source on S22 that needs authorising first | S22
In | A GitHub push that failed because the installation was revoked | `E058`
Out | A provider's own consent screen, and back | The provider, then this screen
Out | GitHub's own installation settings, in a new tab | `github.com`, the installation page
Out | The agent-token flow, once the agents card leaves the Later column | Undecided, see `D57`
Out | Any other settings section | `C141`

**Every connection can be removed here, and also at the other end.** That is the promise the page
opens with, and it is the reason the GitHub card links out rather than pretending we own the grant.

**A card is a list of claims, not a description.** Every line says one thing the connection may do,
or one thing it may not, so a person can read down the card and know the blast radius.

### The Drive card, claim by claim

Claim | What it says | Where it comes from
The folder | Every save writes the markdown there, and a change made in Drive shows up here within a few minutes | The poll interval below
The scope | Only files this app created or the person picked. We cannot see the rest of the Drive | `drive.file`, at `docs/mvp0/PRODUCT-PLAN.md` section 11
The conflict rule | Conflicts are never merged silently. Both versions are kept and the person chooses | The shared promise string, and S31
Controls | Change folder, pause sync, disconnect | `docs/mvp0/screens/gen.mjs:1433`

**Why the card says a few minutes rather than instantly.** We poll rather than subscribe, because a
change channel lasts a week at most and carries no content, at `docs/mvp0/PRODUCT-PLAN.md` section 11. At a five-minute poll the cost is 30,300 units per connected person per day, which
serves 13,201 people inside Google's daily threshold, at `docs/mvp0/PRODUCT-PLAN.md` section 11, at
line 1017. A one-minute poll would serve 2,749, at section 11, line 1018. **The wording on this card
is a capacity decision, so it must not be tightened without redoing that arithmetic.**

### The GitHub card, claim by claim

Claim | What it says | Where it comes from
The repository | GitHub grants this app the whole repository, and frontmatter only ever writes under the docs folder, and that rule is tested | `docs/mvp0/PRODUCT-PLAN.md` section 11
The permission | The Contents permission, read and write, and nothing else | section 11
The quota | The monthly push allowance and how much of it is used. Pull is unlimited | `limits.github.pushes`
The grant | A GitHub App rather than a personal token, revocable on GitHub at any time | section 11
Controls | Add a repository, manage on GitHub | `docs/mvp0/screens/gen.mjs:1438`

**The docs-only rule is ours, not GitHub's.** GitHub cannot express it, so the card says who is
keeping the promise. An installation token expires after an hour and carries 5,000 requests an hour,
at `docs/mvp0/PRODUCT-PLAN.md` section 11, and every update sends the file's blob hash
and treats a conflict response as a re-read, at section 11, line 1027, which is the splice engine's
compare-and-swap rule in GitHub's own words.

### The agents card

**It is drawn as Later, at reduced opacity, with the MCP server named.** Its rows say what an agent
token may do: read and propose, never apply and never publish. That prohibition is the change queue
on S20 expressed as a permission, and it matches the role matrix at
`docs/mvp0/PRODUCT-PLAN.md` section 19, where an agent token has `Propose` but never
`Apply` and never `Publish`.

**The 18 September research argues the card should not be in Later. That is recorded as `D57` below
and is not decided here.**

## Data contract

What | Direction | Port or store | Shape | When
Connections | read | `Connections.forAccount(accountId)` | One row per provider with its encrypted token, state and settings | On open
Drive folder | read and write | `Connections.settings('drive')` | `{ folderId, folderName, pageToken, pausedAt }` | On open, and on change
Drive poll state | read | The same row | The stored page token the change list is read from | Woken by the watch channel, with a backstop poll every `DRIVE_POLL_INTERVAL`. See `D58`
GitHub installation | read | `Connections.settings('github')` | `{ installationId, repositories, pushesUsed }` | On open
Push quota | read | `limitsFor(account)` | `limits.github.pushes`, `limits.github.repos` | On open
Agent tokens | read | `AgentTokens.forAccount(accountId)` | `{ name, scope, lastUsedAt }`, a hash and never the token | On open, once the card leaves Later
Disconnect | write | `Connections.remove(provider)` | The row is removed and the grant revoked at the provider | On disconnect

**None of this is built.** At `0af3c90` there is no `src/modules/connections/`, no Drive adapter and
no GitHub App installation flow. `src/modules/repository/` speaks to a repository through a token
supplied by configuration, which is not the same thing. The screen is **specified, not built**.

**A token is never shown on this screen.** Not once, not partially, not behind a reveal control. The
card shows the account name, the scope and the last use.

## Actions

Action | Trigger | What happens | Failure behaviour | Event id
Connect Drive | The connect control on the card | The provider's consent screen opens, then the folder picker | Consent refused, so `E098` and nothing is stored | `conn.drive.connected`
Change the folder | Change folder | A new folder is picked. Files already synced stay where they are | Folder no longer exists, so `E042` and the old one stays | `conn.drive.folder.changed`
Pause | Pause sync | Polling and writing stop. Nothing is deleted at either end | none | `conn.drive.paused`
Disconnect Drive | Disconnect | The row is removed and the grant is revoked. Files stay in the person's Drive | Revocation call fails, so `E099` removes the row and names the manual step | `conn.drive.disconnected`
Install on GitHub | Add a repository | GitHub's own installation flow opens | Installation cancelled, so nothing changes | `conn.github.installed`
Manage on GitHub | Manage on GitHub | GitHub's installation settings open in a new tab | none | `conn.github.manage.opened`
Meet the push quota | A push past the monthly allowance | `E075`, which names the count, the reset and the Pro option | none | `conn.github.quota.reached`
Meet a revoked installation | Any call after a revocation at GitHub | `E058`, which says where it was revoked and how to reinstall | none | `conn.github.revoked`
Read the agents card | Opening the page | The card renders as Later, with its rows and the two disabled controls | none | `conn.agents.viewed`
Revoke an agent token | Revoke on a row, once the card is live | That token stops working immediately | Already revoked, so nothing happens | `conn.agent.revoked`

**Disconnecting never deletes the person's files** at the other end. The card says so before the
control is pressed.

## States

State | When | What is shown | What the person can do
first-run | No connection yet | Three cards, each offering to connect, with its claims already visible | Connect, or read.
empty | The same as first-run. This screen lists a fixed set of providers | The three cards | Connect.
loading | The connection rows are being read | Card shapes with their claims, controls disabled | Wait.
partial | One provider answered, another has not | The answered card is live. The other shows its shape and says it is still loading | Use the live one.
offline | No connection | The last known state is readable, marked as last known. Every control is disabled with one reason | Read, come back.
unauthorised | The grant was withdrawn at the provider | `E099` for Drive, `E058` for GitHub, on that card only | Reconnect, or remove the row.
over-cap | The push allowance is spent, or the repository allowance is | `E075`, on the GitHub card, with the reset date | Wait, or go to Pro.
AI-unavailable | n/a. Connections call no model | n/a | n/a.
conflict | A file changed at both ends | Nothing is merged. Both versions are kept and the person chooses on S31 | Resolve on S31.
error | A provider call failed for any other reason | The card names the failure and keeps its last known state | Retry, pause, or disconnect.
degraded | A provider is rate-limiting us | The card says sync is slower than usual and names the interval | Wait, or pause.

## Keyboard and focus

key | does
Tab, Shift Tab | Moves through the settings navigation, then each card's controls in order
Enter, Space | Activates the focused control
Escape | Returns focus to the settings navigation

**Focus on arrival is the Connections item in the settings navigation**, so a person knows where they
are in the section list.

**Disabled controls stay in the tab order and say why they are disabled**, because a control that
vanishes is harder to understand than one that explains itself. The agents card's two controls are
the case this rule exists for.

**Checked 18 September, no collision `[O]`.** File 15 section 2 proposes `Cmd/Ctrl + ,` to open
Settings, marked `PROPOSED`, and binds nothing inside it. The keys above are the platform's own on a
focused control, and Escape here moves focus only when no layer is open, per its section 5.

## Responsive

- **The settings navigation becomes a drawer** at phone width, reached from the menu control.
- **Two cards are shown**, Drive and GitHub, as drawn at `docs/mvp0/screens/gen.mjs:1449`. The agents card is Later and
  adds nothing on a phone until it is live.
- **The claim lines stack** with the icon above the sentence rather than beside it.
- **The controls go full width** at thumb height, with disconnect last and visually quietest.

## Desktop differences

- **A watched folder on disk is a fourth kind of connection**, and it belongs on this page when it
  ships. It has no provider, no token and no revocation at the other end, so its card is a folder
  path and a stop control.
- **The GitHub and Drive flows open in the system browser** rather than in the app window, because a
  consent screen inside an application window is the shape a phishing page takes.

## What this screen must never do

- **Never show a token**, in any form, including a masked one.
- **Never ask for a scope wider than the card states.**
- **Never let a disconnect delete the person's files** at the provider.
- **Never grant an agent token the right to apply or publish.**
- **Never promise a sync latency the poll interval cannot meet.**
- **Never claim GitHub enforces the docs-only rule.** We do, and the card says so.
- **Never hide a disabled control.** Leave it and say why.
- **Never merge a two-ended change silently.**

## Open questions

id | question | why it is open
`D57` | **Whether the MCP server moves out of the Later column.** The plan and the drawn screen both put the agents card in Later, at `docs/mvp0/PRODUCT-PLAN.md` section 5 and at `docs/mvp0/screens/gen.mjs:1439`. The research of 18 September argues the opposite, and this file does not decide it | Two findings from that round bear on it. First, demand: `docs/research/2026-09-18/raw/Z3-agent-tool-demand.md` measured open issues on public trackers on 18 September and found 333 reactions across two issues asking one tool for MCP support, and 409 on a request to join a coding agent to the place documents live. Its own conclusion is that parking the server in Later is the wrong call. Second, feasibility: `docs/research/2026-09-18/raw/Z4-mcp-reachability.md` opened the specification dated 2026-07-28 and found a standard remote transport over HTTP, authorisation built on OAuth 2.1 with the server as a resource server, and per-operation scopes that map onto our own permission model without inventing anything. **Both are read-only findings. The column is a founders' call, and the cost of moving it is a phase, not a screen**.
`D58` | Whether the Drive poll stays at five minutes as the connected-user count grows | The interval is a capacity decision, at `docs/mvp0/PRODUCT-PLAN.md` section 11, and the card's wording is downstream of it.
`D59` | Where a watched folder on the desktop appears, given that it has no provider and nothing to revoke | It is a connection in every practical sense and in no technical sense, and nothing in the plan places it.

**Resolutions.** None of these is `[Z]`.

- **`D57`, needs founder.** It is `D04` in `56-OPEN-DECISIONS.md`, still open, and moving it moves a

    `50-ROADMAP.md`, and the agents card leaves Later with it.

  - Rejected: holding it in Later, against the demand the research measured.
- **`D58`, resolved (proposed 18 Sep, founder review).** Already settled in

    at sixty about 102,564. The capacity question stops scaling with the poll.
  - The card keeps "within a few minutes", which the channel meets. Only a lost notification waits
    for the backstop, and a late mirror edit is a proposal, so nothing is lost.
  - `A126` must be tested with the channel live, not against the poll alone.
- **`D59`, resolved (proposed 18 Sep, founder review).** On this page, as a fourth card, "This
