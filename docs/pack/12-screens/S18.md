## Purpose

Let a stranger, or an agent, read a published document immediately, with no account and nothing in
the way.

## The rule that governs this screen

**Content first, invitation second. This one is absolute.**

The founders decided it on 18 September, recorded at
`docs/mvp0/SCREEN-CHANGES-2026-09-18.md:311`, and the reasons are measured rather than preferred:

- **Agents outread humans close to two to one**, and **83 per cent of them arrive by the markdown
  route**, at `docs/mvp0/SCREEN-CHANGES-2026-09-18.md:316`. A gate that detects a desktop app is
  invisible to every one of those readers.
- **An install prompt in front of a shared link is hostile to the person who was sent it**, and this
  page is the top of the funnel, at `docs/mvp0/SCREEN-CHANGES-2026-09-18.md:318`.
- **Probing for a desktop app on every load costs latency** on the one surface that must be fast, at
  `docs/mvp0/SCREEN-CHANGES-2026-09-18.md:320`.

What that means, in four lines:

1. **The page paints with no gate, no redirect and no probe before first paint.**
2. **`page.md` and `llms.txt` are never gated, never redirected and never given an interstitial.**
   That covers every non-HTML route, at `docs/mvp0/SCREEN-CHANGES-2026-09-18.md:325`.
3. **After first paint, a dismissible bar offers where to open it.** It is an offer. Dismissal is
   remembered.
4. **The sign-in boundary is editing, not reading.** A reader who presses Edit meets sign-in, and that
   costs nothing at the top of the funnel.

## Data contract

What | Direction | Port or store | Shape | When
Published record | read | `PublishStore.bySlug(slug)` | `{ documentId, slug, versionKey, branded, publishedAt }` | On request, server side
Rendered body | read | R2 object at the version key | The rendered page | With the record
Raw markdown | read | The same version key | The bytes on disk, unchanged | On the markdown route
Machine index | read | `PublishStore.llms(slug)` | A text index of the page and its sections | On the llms route
Link password | read | `ShareWriter` record | A hash. The submitted password is compared and never stored | Only on a password-protected link
Dismissal | write | The reader's own browser storage | `{ dismissed: true }`, per origin | On dismissing the open-in bar
Protocol handler | read | The browser's own registration | Present or absent | After first paint, never before

**`isPublicPath()` in `src/proxy.ts:59` is where this rule is enforced today.** It already makes
`/p/<slug>` public at `src/proxy.ts:78`, and `isPublicSlugPath` at `src/proxy.ts:51` makes `/<slug>`
public.

**Two gaps are real and open at `0af3c90`, and both breach the absolute rule.**

Route | What happens today | Why
`/<slug>.md` | Redirected to the sign-in page | `SLUG_PATTERN` at `src/proxy.ts:50` allows no dot, and `PUBLIC_STATIC_RE` at `src/proxy.ts:15` has no `md` in its extension list
`/<slug>/llms.txt` | Redirected to the sign-in page | `PUBLIC_STATIC_RE` matches only a single top-level segment, as its own comment at `src/proxy.ts:85` says

**Both must be fixed in the same commit as any work on this screen**, and the fix belongs in
`isPublicPath()` rather than in a per-file exception. A redirect on the markdown route is the exact
failure this screen exists to prevent, and it is invisible in local testing because a login page
returns 200 after a redirect.

**`E340` is a not-found, not a redirect.** An unpublished slug tells the reader it is not there. It
never bounces to sign-in, because a bounce turns a dead link into a login wall for an agent.

## States

State | When | What is shown | What the person can do

empty | A published document with no body | The title, the footer, and one line saying the document is empty | Read the twin, report.
loading | Before the body arrives | Nothing is gated. The body streams. The bar waits for first paint | Read as it lands.
partial | A fenced block fails to render | The block is shown as a code block with its own text intact | Read, copy, download the twin.
offline | The reader has no connection | The browser's own offline page. We add nothing | Reconnect.
unauthorised | n/a for reading. Reading needs no account | n/a | n/a.
over-cap | The owner is over the published-page cap | Pages already published keep serving. Nothing new publishes | Nothing. This is the owner's problem, on S33.
AI-unavailable | n/a. Nothing here calls a model | n/a | n/a.
conflict | n/a. A published page is a snapshot of one version | n/a | n/a.
error | The rendered object is missing | `E344`, and the markdown twin is offered, because the bytes may still be readable | Read the twin, report.

## Keyboard and focus

Escape | Dismisses the open-in bar

**Focus on arrival is the document body**, not the bar and not the card. The page exists to be read,
and a reader who lands with focus on a promotional bar has been sold to before they were served.

**The open-in bar is announced politely**, in a live region that does not interrupt, because it

## Responsive

- **Single column at phone width**, with the header controls collapsing to the download control and
  the open-in control.
- **The open-in bar becomes a single row** with the two options side by side and the dismissal as an
  icon.
- **No bottom bar.** The published page is not the workspace, and a reader who has no account has
  nothing to navigate to.
- **The password gate is the phone's drawn state** at `docs/mvp0/screens/gen.mjs:1341`, centred, with the same footer as
  the desktop page.

## Desktop differences

- **The Tauri build registers a protocol handler.** That registration is what the open-in bar detects,
  and it is the only reason the app option ever appears.
- **The bar still never probes before first paint.** Detection happens after, in the browser, using
  what the browser already knows.
- **There is no published-page surface inside the desktop app itself.** Opening a published page in
  the app opens the document, not this screen.

## What this screen must never do

- **Never gate, redirect or interstitial the markdown route or the machine index.** This is absolute
  and it covers every non-HTML route.
- **Never probe for anything before first paint.** No auth check, no app detection, no analytics call
  that blocks.
- **Never redirect a missing page to sign-in.** Not found is not found.
- **Never show the open-in bar over the document.**
- **Never ask for an account to read.** The boundary is editing.
- **Never show a captcha or a puzzle**, on this screen or any other.
- **Never let the password gate say whether a document exists.** A wrong password and a missing
  document read the same.
- **Never index a page the owner has not chosen to index**, which is still an open decision.
