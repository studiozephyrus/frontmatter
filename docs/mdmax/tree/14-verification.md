**D17 · `S13-appendix §13.1.4 (the derivation script)`**
- **Claim:** The ten-line `scripts/derive/corpus-id.py` containing: `print(f"lines={len(lines)} blob_bytes={len('\n'.join(lines).encode())}")`

- **Correction:** Change the print line to avoid the backslash inside the f-string expression, e.g. hoist the blob: replace the two lines
```
digest = "sha256:" + hashlib.sha256("\n".join(lines).encode()).hexdigest()
print(f"lines={len(lines)} blob_bytes={len('\n'.join(lines).encode())}")
```
with
```
blob = "\n".join(lines).encode()
digest = "sha256:" + hashlib.sha256(blob).hexdigest()
print(f"lines={len(lines)} blob_bytes={len(blob)}")
```
Output is unchanged and it parses on every Python 3.x.
