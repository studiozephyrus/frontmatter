## 6. The check

The extraction regex was `\bA\d{3}\b` over each screen, with a table row read as
`id | text | test`. The check below reads the map, the file and all 38 screens.

```python
import json, re, glob
PACK = 'docs/pack'
import sys
m = json.load(open(sys.argv[1] if len(sys.argv) > 1 else f'{PACK}/tools/acceptance-map.json'))
f = open(f'{PACK}/19-ACCEPTANCE-CRITERIA.md').read()
defined = set(re.findall(r'^`(A\d{3})` \|', f, re.M))
tok = re.compile(r'\bA\d{3}\b')
screens = sorted(glob.glob(f'{PACK}/12-screens/S*.md'))
missing_in_map, bad_targets, after_unhomed = [], [], set()
for p in screens:
    sid = p.split('/')[-1][:-3]
    toks = set(tok.findall(open(p).read()))
    for t in sorted(toks):
        if t not in m.get(sid, {}): missing_in_map.append((sid, t))
    for t, tgt in m.get(sid, {}).items():
        if t not in toks: bad_targets.append((sid, t, 'token not on screen'))
        if tgt not in defined: bad_targets.append((sid, t, tgt))
    after = {m[sid].get(t, t) for t in toks}
    after_unhomed |= {a for a in after if a not in defined}
pairs = sum(len(v) for v in m.values())
distinct = len({t for v in m.values() for t in v})
print(f'screens in map: {len(m)} of {len(screens)}')
print(f'(screen, token) pairs in map: {pairs}; distinct screen tokens: {distinct}')
print(f'criteria defined in 19: {len(defined)}; distinct map targets: {len(set(t for v in m.values() for t in v.values()))}')
print(f'tokens on a screen but missing from the map: {len(missing_in_map)}')
print(f'map targets not defined in 19, or tokens not on their screen: {len(bad_targets)}')
print(f'A ids still without a home if the map were applied: {len(after_unhomed)}')
print('RESULT:', 'PASS' if not (missing_in_map or bad_targets or after_unhomed) else 'FAIL')
```

A red proof was run first: one target changed to `A999` and one token deleted from a copy of the
map. The check printed `RESULT: FAIL`, with one missing token, one bad target and two unhomed ids.

## 8. Limits of this reconciliation

- **No screen was edited.** `validate-pack.py` still reports 165 unhomed `A` ids until the map is
  applied. The check above simulates the application; it does not perform it.
- **Other files cite `A` ids too**, such as `07-CLAIMS-REGISTER.md` and the register's
  `acceptance` column. They were out of scope and were not reconciled.
- **Identity was judged by reading**, row by row, not by a string match. A reader who disagrees
  that S17 `A108`, a second live collaborator, is the file's third person joining two, should say so.
- **No criterion was executed.** Every new row is a proposal with a proposed `T` id.
- **What would falsify it.** A screen token whose target states a different fact from the screen
  row. Section 2 lists every pair, so each is checkable by eye.
